# PhononTTS
A python GUI for auto-installing and auto-configuring and generating audio from a bunch of voices, with PhononTTS.

<img width="1182" height="892" alt="image" src="https://github.com/user-attachments/assets/8dd87675-691b-40b5-8e3d-f4020ad77153" />

Just click the .bat file on windows and wait for it to auto-configure everything. 

Its similar to Kokoro and Supertonic and all the other TTS GUIs I already made for you.

That's it. Done! Everything will set itself up! 

Enjoy the new human sounding voices at faster speeds, compared to Kokoro and Supertonic.
